# Guia para agentes

Use a skill para planejar ou revisar viagem, não para autorizar compra. Leia [SKILL.md](../skills/planejar-viagem/SKILL.md) e gere o guia a partir do [template](../skills/planejar-viagem/assets/roteiro.html). Nunca copie exemplos reais para o Git. Roteiro executável: origem aproximada, trechos de ida e volta, base, custos, clima e plano B dentro dos modos aceitos. Uma escolha com teto; até três opções distintas sem teto quando houver evidência.
