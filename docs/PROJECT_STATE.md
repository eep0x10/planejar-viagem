# Estado do projeto

O pacote reúne instruções em português e um template offline, sem runtime próprio. Busca atual, criação de arquivo e verificação visual dependem das capacidades do agente que executar a skill. O template é um ponto de partida sintético; não representa nenhuma viagem real. Próximo passo em mudanças futuras: rodar os casos de [teste](TESTING.md) e atualizar a documentação.
