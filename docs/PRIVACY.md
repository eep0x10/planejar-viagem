# Privacidade

Versione apenas instruções, documentação, modelos vazios e exemplos inventados. Não inclua reservas, datas e rotas pessoais, nomes, e-mails, endereços residenciais, coordenadas, documentos, comprovantes, QR codes, localizadores, capturas, links privados, tokens, `.env` ou históricos de conversa. Não copie saídas reais nem as use como base de um exemplo. Confira também metadados e URLs. Use uma lista explícita de arquivos, revise o diff e confirme a visibilidade antes do envio. `.gitignore` é uma rede extra, não substitui revisão.
