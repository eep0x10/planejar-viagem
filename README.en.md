# Travel Planning Skill

[Português](README.md)

A Portuguese-first agent skill for one or two travelers. It researches door-to-door routes, accommodation, food, activities, costs and weather. It produces a standalone HTML guide, distinguishes estimates from confirmed bookings, and does not buy, book or contact anyone by itself.

Clone this repository using an account with access. Copy the complete `skills/planejar-viagem` folder to your agent's skills directory (for Codex, for example, `~/.agents/skills/`). Keep `assets/roteiro.html` with `SKILL.md`.

See [agent instructions](AGENTS.md), [privacy](docs/PRIVACY.md), [testing](docs/TESTING.md) and [project state](docs/PROJECT_STATE.md). The repository intentionally contains no real itinerary, booking, receipt or personal data.
